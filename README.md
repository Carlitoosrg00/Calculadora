# 🧮 Calculadora Java (GUI)

Una aplicación de escritorio gráfica desarrollada en **Java** con la librería **Swing/AWT**, diseñada para realizar operaciones matemáticas básicas con una interfaz intuitiva, moderna y limpia.

---

## 🚀 Características

- **Operaciones Básicas:** Suma, resta, multiplicación y división.
- **Funciones Adicionales:** Limpieza de pantalla (`C` / `AC`), cambio de signo (`+/-`) y cálculo de porcentajes.
- **Interfaz Gráfica (GUI):** Diseñada de forma clara y responsive con contenedores y layouts de Swing.
- **Manejo de Excepciones:** Control de errores común (como la división por cero).

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Java (JDK 8 o superior)
- **Interfaz Gráfica:** Java Swing / AWT
- **IDE Recomendado:** Eclipse / IntelliJ IDEA / NetBeans
